# SqlServerConnectionApp

A C# application for managing and testing SQL Server connections.

## Overview

This application provides a straightforward interface for connecting to SQL Server databases and executing queries.

## Features

- SQL Server connection management
- Query execution and testing
- Connection string configuration

## Requirements

- .NET Framework or .NET Core runtime
- SQL Server instance (local or remote)

## Getting Started

1. Clone the repository
2. Open the solution in Visual Studio
3. Configure your SQL Server connection details
4. Build and run the application
